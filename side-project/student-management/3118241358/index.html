[一言不合自己寫 3] 我老婆的 Line 記事本，被我這個工程師老公收編了

發表於 2026-06-01 更新於 2026-05-23 分類於 side-project
太太用 Line 記事本管學生、記收入、發通知，身為工程師老公的我表示這絕對不行。於是做了一套學生管理工具給她用。

這篇沒有什麼了不起的技術，只有一個工程師老公的一點點雞婆。🙃

前情提要

我老婆是位音樂老師。

她平常的工作大概是這樣的 ——

白天在自己家裡接學生，一對一上課；晚上則跑去幾間音樂補習班，以鐘點費的方式幫忙代課。學生有大有小，有的固定一週一次、有的會臨時調課，有的繳月費、有的繳單堂。

聽起來工作其實還算單純。

但她管理這些事情的方式 ——

全部都在 Line 的記事本裡。

對，就是那個 Line 群組裡，可以「釘留言」的那個記事本 XD


痛點 1：學生資料散在記事本

每個學生一則記事本，內容大概長這樣：

要找某個學生的資料，就 ——

往上滑、往上滑、再往上滑。一年下來，要翻到一月份的紀錄，可能要先做個熱身運動。


痛點 2：「這個月到底收了多少錢？」

每次月底，我問她：「這個月收入大概多少？」

她會給我一個非常專業的回答：

「⋯⋯欸我算一下喔。」

然後就是 30 分鐘以後的事情了 ——

她得把每個學生的記事本一則一則打開，數這個月上了幾堂、有沒有人預繳、有沒有人欠款、補習班那邊鐘點費又是多少 ⋯⋯

每次算完，她都會說一句：「啊，我覺得應該還有漏的。」

身為工程師，我聽到「應該還有漏的」這幾個字，整個人都不對勁。


痛點 3：上課前要手動 Line 通知學生

她有個固定的習慣：上課前一兩小時，要傳訊息提醒學生「等等記得來上課喔」。

聽起來很簡單對吧？

但一天有 5、6 個學生的時候，就要打開 5、6 個對話框、複製貼上 5、6 次「Hi 小明～等等 18:00 記得來上課喔！」。

而且 ——

有時候上課上到一半才想起來，下一個學生忘了通知。


痛點 4：補習班的鐘點課表，全憑記憶

她在外面幾間音樂補習班有兼課，每週的時段不太一樣，有時候會有臨時加場、有時候又會被取消。

那她怎麼記呢？

用腦袋記。

對，就是用她那顆同時要記學生姓名、樂理、曲目、學生家長綽號的腦袋去記。

偶爾就會出現經典畫面：

「欸，今天不是要去 OO 補習班嗎？」
「⋯⋯啊，我以為是明天！」


「現在已經 2026 年了」

某天晚上，我又看著她在 Line 記事本上來回滑動、用計算機按月收入、一個一個傳訊息給學生 ——

身為工程師，我內心 OS 已經開始默默 compile error 了：

現在已經 2026 年了，老婆又剛好有個工程師老公，這怎麼可以？😤

於是我決定 ——

一言不合，自己寫一個給她用。


做了什麼

考量到她平常主要是用手機在處理這些事情（畢竟上課中還要打開電腦太誇張了），所以我做成一個 PWA（Progressive Web App）。

她可以把網頁加到 iPhone 桌面，看起來就跟一般 App 一樣，但我不用花時間搞 iOS 上架（對，我就懶）。

技術棧很簡單：React PWA 當前端、Go 當後端、PostgreSQL 存資料、LINE Messaging API 處理通知。整包丟到 VPS 上，跑個 Docker 就上線。

這篇就不展開細節了，下面分幾個區塊講一下她實際在用的功能。


功能 1：學生與課程的「正常」管理

最基本的部分。每位學生有自己的頁面，可以看到：

  • 基本資料（年齡、家長 Line、學費單價）
  • 上課歷史（哪一天上了、哪一天請假、補課補在哪天）
  • 收費狀況（這個月還欠幾堂、預繳剩幾堂）

跟記事本最大的差別是 ——

不用再滑了。

她最常用的功能之一是「學費池」：學生一次預繳 10 堂，每上一堂就從池子裡扣一堂，剩幾堂一目了然。要是不小心上超過了，系統會跳紅字提醒「超用 X 堂」，免得月底才發現少收錢。


功能 2：LINE Bot 自動發出席通知

這個是她最有感的功能。

設定好上課時段之後，系統會自動在上課前幾小時，透過 LINE Bot 推訊息給學生。

訊息裡有兩個按鈕：「我會到」、「我請假」。

學生點下去之後 ——

老師這邊就會收到結果，不需要再追問。

而且為了避免學生手殘亂按，我還加了一個「不會重複通知」的小機制（畢竟學生已經回應過了，就不需要再被打擾）。

她用了第一週後跟我說：

「我覺得，這個東西讓我每天少打 30 則訊息。」

雞婆值 +1。


功能 3：鐘點費課表 ＆ 月結

針對她在外面補習班的兼課場次，我做了一個獨立的「鐘點費課表」。

每週固定的時段、臨時加場、被取消的場次，都可以在裡面登記。

每個月底，系統會自動依鐘點費單價算好「這個月在 A 補習班上了幾堂、總共多少錢」，整整齊齊一張表。

從此以後 ——

不用再用腦袋記今天到底是不是要去 OO 補習班，也不用月底拿著計算機在那邊敲半天。


後記

這個 side project 開發了大概一個多月。

中間用了不少 AI 工具幫忙 vibe coding，自己只負責「我老婆會怎麼用？」、「這個畫面對她來講會不會太複雜？」這種事情。實作的部分，AI 幫了非常大的忙（不然我下班還要寫 code 真的會崩潰）。

上線之後我最有感的瞬間是 ——

有一天晚上她跟我說：

「欸我發現，我已經一個禮拜沒打開 Line 的記事本了。」

那一刻我覺得這個 side project 已經值回票價了。

雖然這個工具只有她一個使用者，目前也沒有打算開放給其他老師用（畢竟每個老師的收費方式、上課習慣都不太一樣，要做成通用版本工程量太大）——

但對我來說，能用自己的專業，把另一半每天在抱怨的麻煩事拿掉，那種感覺其實還蠻浪漫的。

寫程式的浪漫，大概就是這個樣子吧。😘


這篇沒什麼技術深度，比較像是一篇生活紀錄。如果你也剛好有一個總是用 Line 記事本記東西的另一半 ——

歡迎來訊跟我聊聊（不過工具我暫時還不打算開源啦 XD）。

最後感謝你的閱讀囉，我們下次見！Bye ～
